## Part 1 — Instagram

### Positioning

Don't make a generic **"AI News 🤖"** account.

Make the promise:

> **"We find the AI tools and workflows actually worth using."**

Your content should answer one of four questions:

- What should I use?
- How does it work?
- Is it actually good?
- How can I save time/money with it?

### Content Pillars

| # | Pillar | Weight | Example Topics |
| --- | --- | --- | --- |
| 1 | AI Tools | 30% | "5 AI tools that save developers hours every week", "This free AI tool converts documentation into code" |
| 2 | AI Coding | 25% | "3 prompts for Claude Code", "Stop giving your coding agent this kind of prompt" |
| 3 | GitHub / Open Source | 20% | "5 underrated AI repos", "This repo gives you your own AI coding assistant" |
| 4 | Agentic AI | 15% | "RAG vs AI agents", "How an AI agent actually works" |
| 5 | Productivity / Career | 10% | "How developers can use AI without becoming dependent on it" |

### Weekly Schedule

| Day | Main Post |
| --- | --- |
| Monday | AI tool carousel |
| Tuesday | Coding tip Reel |
| Wednesday | GitHub discovery carousel |
| Thursday | AI agent Reel |
| Friday | "5 tools this week" carousel |
| Saturday | Practical workflow Reel |
| Sunday | Weekly AI roundup |

Start with **1 main post/day**. Don't immediately chase 3–5 posts/day. Quality + consistency first.

### Carousel Structure

Every carousel follows roughly:

| Slide | Content |
| --- | --- |
| 1 | **BIG HOOK** |
| 2 | The problem |
| 3 | The solution |
| 4–7 | Useful information |
| 8 | Practical example |
| 9 | Who should use it |
| 10 | CTA |

**Strong hook example:**
> "I tested 7 AI coding tools. Only 3 are worth keeping."

Much stronger than:
> "7 amazing AI tools! 🔥🔥🔥"

### Reel Structure

Keep most early Reels around **20–60 seconds**.

| Timestamp | Section |
| --- | --- |
| 0–2 sec | HOOK |
| 2–8 sec | Problem |
| 8–35 sec | Demo |
| 35–50 sec | Result |
| Final seconds | CTA |

**Example hook:**
> "This AI agent can read an entire GitHub repo. Watch what happens when I give it this task."

Then actually show it. That demonstration is what separates your account from AI-generated content farms.

### Automation Pipeline

```text
                DAILY
                  ↓
           Source discovery
                  ↓
           Research agent
                  ↓
          Validation agent
                  ↓
            Topic scoring
                  ↓
         Content generation
                  ↓
        Visual generation
                  ↓
           Quality check
                  ↓
         Human approval
                  ↓
          Instagram publish
                  ↓
            Analytics
                  ↓
         Strategy database
```

Initially keep **human approval**. Once the system consistently produces good posts, automate more aggressively.

## Part 2 — YouTube

Instagram should be **fast**. YouTube should be **deep**.

### Positioning

> **"We test AI tools and explain how developers can actually use them."**

### Content Pillars

| # | Pillar | Example Topics |
| --- | --- | --- |
| 1 | **Tool testing** | "I tested 10 AI coding agents" |
| 2 | **Tutorials** | "Build an AI agent with Python" |
| 3 | **Comparisons** | "Claude Code vs Codex vs Gemini CLI" |
| 4 | **Open-source projects** | "5 GitHub AI projects you should know" |
| 5 | **Real experiments** *(potentially strongest)* | "I gave 3 AI agents the same coding task", "Can AI build a complete app without me?" |

These create curiosity and are harder to commoditize.

### Schedule

Start with **2 long-form videos/week**:

| Day | Content Type | Example |
| --- | --- | --- |
| Tuesday | Research / comparison | "I tested 8 AI coding agents" |
| Saturday | Tutorial / experiment | "I built an AI developer workflow using 5 open-source tools" |

Then extract **3–5 Shorts/week** from those videos.

### Video Formula

```text
HOOK
↓
What are we testing?
↓
Why should you care?
↓
Experiment/demo
↓
Results
↓
Comparison
↓
Who should use it?
↓
Final recommendation
↓
CTA
```

**Avoid:**
- 30 seconds of logo animation
- Generic introduction
- 10 minutes of AI narration

Get to the interesting part immediately.

### Production Automation

```text
TOPIC
  ↓
Research agent
  ↓
Outline
  ↓
Script
  ↓
Source verification
  ↓
Demo / screenshots / code
  ↓
Voice
  ↓
Editing
  ↓
Thumbnail
  ↓
Title
  ↓
Human review
  ↓
Upload
  ↓
Analytics
```

> For videos: **screen recordings + demonstrations + diagrams + narration** rather than completely synthetic "AI avatar talking" videos. That keeps the content useful and makes your channel more credible.

### Monetization Layers

| Layer | Source |
| --- | --- |
| 1 | YouTube Partner Program / ads (1,000 subs + 4,000 watch hours, or 10M Shorts views in 90 days) |
| 2 | Affiliate links (e.g. AI coding tool → referral → commission) |
| 3 | Sponsors ("This video is sponsored by…") |
| 4 | Your own products |

## Part 3 — The Shared AI Engine

> This is the part to spend most engineering effort on.

### Research Sources

Your system continuously monitors:

- GitHub
- Hacker News
- AI company blogs
- Product launches
- Research papers
- Developer blogs
- Reddit
- Product documentation
- RSS feeds

Don't blindly scrape everything. The research agent should identify **potentially useful discoveries**.

### Topic Scoring

Every candidate topic gets scored across 6 dimensions:

| Dimension | Score |
| --- | --- |
| Usefulness | 0–10 |
| Novelty | 0–10 |
| Developer Value | 0–10 |
| Search Demand | 0–10 |
| Monetization | 0–10 |
| Ease of Demo | 0–10 |

**Total score → Top topics selected**

This prevents: *"AI generated a post because there was nothing else to post."*

### The Killer Feature: Verification

Before publishing any claim:

```text
CLAIM
  ↓
Source found?
  ↓
YES
  ↓
Is source reliable?
  ↓
YES
  ↓
Can we reproduce it?
  ↓
YES
  ↓
✅
```

**For GitHub projects specifically:**

```text
Repository
   ↓
README
   ↓
Releases
   ↓
Recent commits
   ↓
Issues
   ↓
License
   ↓
Installation
   ↓
Test
   ↓
Score
```

This is a huge differentiator. You're building **AI content with evidence** rather than **AI-generated opinions**.

## Part 4 — The Tech Stack

Optimized to be **inexpensive**.

| Layer | Technology |
| --- | --- |
| AI (local) | Ollama + Qwen |
| Orchestration | n8n |
| Backend | Python |
| Database | PostgreSQL (or SQLite initially) |
| Content generation | Python + templates + image-generation tooling |
| Instagram publishing | Meta/Instagram publishing APIs |
| YouTube publishing | YouTube Data API |
| Storage | S3-compatible / cloud object storage |
| Analytics | Self-hosted (see Part 5) |

## Part 5 — The Most Important Database

Don't just store posts. **Store everything.**

| Category | Tables |
| --- | --- |
| Discovery | `topics`, `sources`, `tools`, `repositories`, `research`, `claims` |
| Content | `posts`, `videos`, `scripts`, `hooks` |
| Distribution | `platform_metrics` |
| Revenue | `affiliate_links`, `products`, `conversions` |

### Analytics Fields Per Post

| Field | Description |
| --- | --- |
| `post_id` | Unique identifier for the post |
| `topic` | Content topic / pillar category |
| `format` | Carousel, Reel, Short, Long-form video |
| `hook` | The opening hook used |
| `date` | Publish date |
| `impressions` | Total times shown |
| `views` | Total views (video) |
| `likes` | Like count |
| `comments` | Comment count |
| `shares` | Share count |
| `saves` | Save/bookmark count |
| `profile_visits` | Profile visits driven by post |
| `link_clicks` | Clicks on bio/link |
| `email_signups` | Email signups attributed to post |
| `revenue` | Revenue attributed to post |

Eventually you can ask:

> **"Which topics have generated the most revenue per 10,000 views?"**

That's much more valuable than knowing which post got the most likes.

## Part 6 — The Self-Improving Loop

Every week:

```text
ANALYTICS
    ↓
What performed?
    ↓
What generated clicks?
    ↓
What generated revenue?
    ↓
What topics are growing?
    ↓
Update strategy
    ↓
Generate next week's content
```

**Example output:**

| Content Type | Engagement Rate |
| --- | --- |
| AI news | 2.1% |
| AI tools | 5.8% |
| Coding workflows | 8.2% |
| Agent experiments | 11.4% |
| Generic motivation | 0.6% |

The system learns: produce fewer generic posts, produce more agent experiments. **That's a real feedback loop.**

## Part 7 — 90-Day Plan

| Phase | Days | Instagram | YouTube | Focus |
| --- | --- | --- | --- | --- |
| Foundation | 1–14 | 20–30 posts (manual/semi-auto) | 2 videos | Build pipeline, find your voice |
| Launch | 15–30 | 1 post/day | 1 video/week | Go live, collect emails |
| Scale | 31–60 | 7–10 posts/week | 2 long-form + 3–5 Shorts/week | Affiliate experiments, funnel tracking |
| Optimize | 61–90 | Automated scoring + repurposing | Better thumbnails/titles | Identify 3–5 winning formats |

### Days 1–14: Build the Foundation

Don't worry about followers. Build:

```text
Research
↓
Topic scoring
↓
Content generation
↓
Templates
↓
Database
```

- Create 20–30 high-quality posts manually/semi-automatically
- Create 2 YouTube videos
- Purpose: finding your voice

### Days 15–30: Launch

- **Instagram:** 1 post/day
- **YouTube:** 1 video/week initially
- Start collecting email addresses
- Create a simple free resource: *"50 AI Tools for Developers"* (lead magnet)

### Days 31–60: Increase Output

- **Instagram:** 7–10 posts/week
- **YouTube:** 2 long-form/week + 3–5 Shorts/week
- Begin affiliate experiments

**Track the full funnel:**

```text
Reach
↓
Profile visit
↓
Link click
↓
Email signup
↓
Affiliate click
↓
Revenue
```

### Days 61–90: Optimization

Now the automation becomes smarter. Add:

- Automatic topic scoring
- Analytics feedback
- Content repurposing
- Better thumbnail/title generation
- Affiliate tracking
- Content backlog

You should finish this phase knowing: *"These are the 3–5 content formats/topics that reliably get attention."*

## Part 8 — What Success Looks Like

Don't set *"I want 1 million followers."* Set milestones around the **business**.

| Milestone | Target |
| --- | --- |
| 1st | 100 useful pieces of content |
| 2nd | 1,000 genuine followers |
| 3rd | 500 email subscribers |
| 4th | First ₹1,000 earned |
| 5th | ₹10,000/month |
| 6th | ₹50,000/month |
| 7th | ₹1L+/month |

The numbers aren't guaranteed — they're checkpoints to see whether the underlying system is working.
